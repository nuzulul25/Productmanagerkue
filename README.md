# Project Manager Kue

Project Manager Kue adalah aplikasi web sederhana untuk mengelola data produk kue/bakery menggunakan PHP dan MySQL dengan tampilan bertema marun.
<img width="946" height="435" alt="image" src="https://github.com/user-attachments/assets/9d9dc16d-8069-4c02-944c-d20299e0073d" />


## Fitur

- Tambah produk kue
- Menampilkan daftar produk
- Edit produk
- Hapus produk
- Pencarian nama dan kategori
- Filter kategori
- Validasi data
- Pagination

## Teknologi

- PHP
- MySQL
- HTML
- CSS
- PDO
- XAMPP
