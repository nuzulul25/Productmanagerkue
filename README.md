# Project Manager Kue

Project Manager Kue adalah aplikasi web sederhana untuk mengelola data produk kue/bakery menggunakan PHP dan MySQL dengan tampilan bertema marun.

## Fitur

- Tambah produk kue
- Menampilkan daftar produk
- Edit produk
- Hapus produk
- Pencarian nama dan kategori
- Filter kategori
- Validasi data
- Pagination

## Teknologi

- PHP
- MySQL
- HTML
- CSS
- PDO
- XAMPP
